    Current foundation¶

    Source synchronization¶

    The 23 October 2026 update advances the public foundation from 8a17e23b to committed source 963d23f1. The Python backend now includes:

    • Thermodynamic models: activity-derived excess and partial-molar properties, finite calibration, six UNIFAC variants, Twu/PPR78 and GE cubic mixing rules, and a common homogeneous-phase property interface.
    • Pure-fluid Helmholtz: native derivatives, thermodynamic properties, density roots, saturation, flash and bounded thermal/process consumers. Fluid coefficients and their provenance are supplied explicitly; no upstream solver is required.
    • Property methods: temperature and parameter derivatives, correlation fitting, scientific conversions and explicit property-selection policies. Data identity review remains in progress; this is not complete coverage of every source table.
    • Engineering calculations: friction and fittings, meters, valves, pumps, packed beds/towers, two-phase and open-channel flow, particle distributions, equipment/tank geometry and atmosphere/solar methods. Correlations have individual application ranges; they do not collectively constitute a general flowsheet solver.
    • Maintenance: shared composition/action helpers replace repeated code. Golden regression expectations have been attributed to their runtime versions; frozen historical reports and their original results remain unchanged.

    The native API guide includes runnable inputs and outputs. The capability website adds examples for Helmholtz, activity thermodynamics, property derivatives and flow-meter inversion, retaining JSON and readable tables. The CPU kernel redesign remains a plan; the shipped implementation uses the native Python backend. This synchronization is a development source update, not a PyPI release, new scientific qualification or performance record.

    Windows / Python 3.11 focused integration initially passed 769/771 checks. The two failures were an optional reference-data setup in the install test and a SciPy-version-dependent golden value. After separating optional empirical inputs and retaining version-specific expectations at the original tolerance, the affected selection passed 17 checks, with 1 optional reference check skipped. That reference install check separately passed on Python 3.12 with reference packages. These overlapping runs are not added together. The actual sdist-to-wheel install, all 70 executable documentation examples, three public-boundary checks, Ruff, the strict bilingual build and 26 browser checks pass.

    Repository-wide typing remains unfinished: mypy reports 3,378 errors versus 3,255 on the preceding public snapshot in the same environment. This update does not claim a green full quality pipeline or new cross-platform scientific qualification.

    Previous public synchronization: 22 October¶

    The 22 October 2026 update imports committed foundation work through source revision 8a17e23b, advancing the previous 8dc31912 snapshot. It includes:

    • Explicit external density/volume sources, including CRC virial data, and source-preserving critical-constant inputs.
    • Seven second- and two third-virial methods, cross parameters, mixture rules and derivatives, plus density/pressure forward and inverse calculations.
    • Pure single-phase gas PVT and caloric consumers and closed, fixed-volume heating through the common coupled solver. General nonideal mixture calorics and open-flow processes remain outside this contract.

    What changed¶

    The native session and domain extensions are now available on top of these existing capabilities. See the native guide for execution, state ownership and model-specific examples, and the extension scope for the delivered models and shared-clock scope.

    Capability Current public behavior
    Materials and vessels Create containers, transfer identified samples, select vessels and route material through declared component ports.
    Component composition Compile compatible capability networks after dependency, state-owner and resource checks; composition reports use component-network and vessel-qualified state owners rather than the old fixed pattern names.
    Full-process crystallization Retain phase inventories, crystal populations and seed provenance through sampling, filtration, resuspension and repeated crystallization. Recovery excludes charged seed and uses tracked initial reagent charge.
    Process control Configure finite ramp/hold programs, queue stages, set feedback and pause/resume advancement. Gas pressure and purge have finite mass and energy accounting.
    Continuous streams Advance finite feed reservoirs, a mixed tank and collected outlets with coupled reaction and thermal dynamics, plus a bounded electrochemical channel.
    Measurement design Configure NMR, IR and MS scan count, resolution and dilution, then acquire a paid, sample-consuming synthetic spectrum. Particle-size measurements are available in compatible crystallization tasks.
    Controlled chemistry Use coupled weak-acid/precipitation worlds with or without an aqueous ion-pair intermediate, and registered crystallization population/occlusion and purification interventions.
    Resources and replay Retain attempted versus committed actions, physical consumption, rejected requests and exactly replayable current-runtime trajectories.
    Scientific records Reusable document storage, versioned notebooks and public-history access are included; study-specific campaign runners are not distributed.

    Operation, component and instrument declarations come from the native module registry; each compiled world and task exposes its compatible subset. Native physical channels retain units while the historical Gym vector is a compatibility projection. Existing classic optimization and optional reinforcement-learning interfaces remain available.

    Model scope¶

    Spectra are calibrated synthetic reporter signals, not predictions of arbitrary molecular structures. Local time remains the default: operating a selected vessel does not advance other vessels. An explicitly configured shared laboratory clock advances all enabled vessels and schedules equipment queues and delayed readings; its supported combinations are listed in the shared laboratory guide. The gas plenum does not dissolve or react with the liquid. The mixed-tank electrical channel is an idealized two-electron model; the separate native battery domain uses bounded SPM, SPMe/DFN and equivalent-circuit models with explicit parameter sets. World-noise shift modes can include a simultaneous physical-parameter change; they should not be treated as pure noise interventions.

    Historical reproduction¶

    The checked-in evidence reports, original manifest and tutorial outputs remain unchanged. They describe their original runtime. The home-page animation also shows a historical trace. Use the pinned notebook links or check out db98e800 before running scripts/verify_release.py. That script verifies the frozen whole tree; it is not a development preflight for current main.

    Current chemistry does not reproduce every old numerical outcome. In particular, the original midpoint partition-world comparison still executes and replays, but no longer meets its old divergence threshold. Current tests retain that negative outcome instead of relabelling the historical qualification as current.
