# 当前基座

2026年10月开发快照同步当前ChemWorld基座，包版本记为 `0.5.0.dev0`。
这是源码更新；现有冻结实验报告仍对应原来的运行时，本次没有发布新的PyPI包。

## 已同步的能力

| 能力 | 当前实现 |
| --- | --- |
| 材料与容器 | 创建容器、转移带来源的样品、选择容器，沿声明的组件端口流转物料。 |
| 组件组合 | 根据依赖、状态归属和资源检查编译兼容的能力网络；报告使用 `component-network` 及带容器名称的状态归属，替代旧固定模式名称。 |
| 完整结晶流程 | 采样、过滤、重悬及重复结晶保留相库存、粒群和晶种来源；回收率排除投加晶种，以追踪的起始反应物为分母。 |
| 持续过程控制 | 设置升温／保持程序、阶段队列和反馈，暂停或继续推进；气压与吹扫具有有限的物料和能量收支。 |
| 连续流股 | 有限储液、混合槽和收集液之间耦合物料、反应及热过程，并提供有限的电化学通道。 |
| 测量设计 | 调整NMR、IR、MS的扫描次数、分辨率和稀释倍数；测量消耗样品、时间及成本。兼容的结晶任务还提供粒径测量。 |
| 可控机理 | 接入酸碱—沉淀耦合网络及水相离子对中间体，以及结晶粒群、杂质夹杂与纯化干预。 |
| 资源与回放 | 区分请求、提交和拒绝，保留物理消耗，支持当前轨迹的精确回放。 |
| 科学记录 | 提供通用文档、笔记版本和公开历史组件；论文专用实验执行器不进入公开包。 |

全局注册表为43类操作、19个世界干预轴、9类仪器（含粒径）；每个任务只开放兼容子集。
此前公开版对应28、12、5。原有经典优化和可选强化学习接口继续保留。

## 运行与验证

```bash
uv sync --locked --extra dev
uv run --no-sync chemworld tasks list
uv run --no-sync python examples/demo_configurable_spectra.py
uv run --no-sync python examples/demo_minimal_agent.py --output runs/minimal-agent.jsonl
uv run --no-sync chemworld verify --submission runs/minimal-agent.jsonl --tolerance 0
uv run --no-sync pytest -q
```

功能检查覆盖多容器、物料流转、控制、连续流、光谱、结晶、失败操作、资源与回放。
没有安装外部参考工具的可选检查会明确跳过。安装检查与贡献方式见
[CONTRIBUTING](https://github.com/sunyrain/ChemWorld-Public/blob/main/CONTRIBUTING.md)。

本次在Windows AMD64上完成466项通过、1项跳过（缺少可选外部IDAES参考）的完整检查，
Ruff、mypy和中英文文档严格构建通过。Python 3.11.15与3.12.10分别验证了wheel和源码包的
独立安装，覆盖15类任务初始化、打包资源、Student Lab及离线示例的精确回放。
这些是软件集成检查，不构成对历史科学报告的重新资格验证。

## 模型范围与旧结果

光谱是合成报告通道，不预测任意真实分子的谱图；未操作的容器不会自行演化；
气体控制尚不包含气体溶解和液相反应；连续流电化学通道也不是完整电池模型。
现有噪声扰动模式可能同时改变物理参数，不应直接作为纯噪声对照。

原始证据、清单和教程输出保持不变，首页动画同样对应历史轨迹。复现旧版请使用固定版本的
notebook链接，或切换到
[`db98e800`](https://github.com/sunyrain/ChemWorld-Public/tree/db98e8002fac0512ed9084a3c8c27985cb9fc405)
后运行 `scripts/verify_release.py`；它核对旧版完整源码，不是当前开发的前置条件。

当前物理模型与旧版不具有逐数值兼容性。旧的相分配世界中点比较仍可执行并精确回放，
但不再达到旧版差异阈值；当前检查保留这个结果，没有把旧资格报告重新标记为新版通过。
