# 当前基座

## 当前维护状态 — 2026年10月31日 {#development-progress}

当前工作集中于通用产品、文档和安装入口的整理。退役研究运行器及其专属评测
已退出产品；当前论文的 notebook 调用安装后的公开 API 组织研究。
历史结果继续对应原执行版本和数据。

新的原生扩展任务已暂停，已交付模型按文档范围继续提供。
完整科学模型执行仍使用 Python；可选 CPU 工作不代表已经覆盖全部数值模型。
软件参考比较也不等于所有材料都获得了真实实验验证。

## 公共源码中已提供的功能 {#source-synchronization}

[公共运行时源码](https://github.com/sunyrain/ChemWorld-Public/tree/main/src/chemworld)
从当前维护的产品同步生成；共享技术指南沿用同一来源，官网保留自己的导航与展示设计。
从[环境作者指南](environment-authoring.md)选择设备并声明操作、资源边界，
再[接入 Agent，按需定义奖励](environment.md)。三步用户奖励示例已随包提供。

| 方向 | 公共版本可用范围 |
| --- | --- |
| 热力学与界面 | 分子／缔合／多流体模型、多相热量闪蒸、有限过程消费和平面界面计算 |
| 反应与生化系统 | 反应器网络、能量输运、导入机理、SBML／COPASI互操作及有界混合动力学 |
| 水处理与电化学 | 有限膜／处理流程、活性污泥、电池参数与滞后族，以及选定半电池和热工作流 |
| 环境使用 | 用户自定义目标与奖励、持久状态、资源边界、观测和回放 |
| 可选 CPU 开发 | 语义声明、资源／历史基础及 C++20 ABI／绑定骨架；尚未建立完整数值模型覆盖 |

官网构建时直接读取公共注册表中的模块、部件、操作和仪器数量。
这些是软件声明数量，不代表独立科学领域数，也不代表任意世界都能使用全部组合。
能力图谱是帮助阅读的内容目录。

通过 Python、CLI 或 Agent 接口使用。旧 Student Lab 命令已退役，
Research Workbench 与 Blender Lab 仍是内部原型。
