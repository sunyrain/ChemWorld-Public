# 当前基座

## 最新开发进展 — 2026年10月25日 {#development-progress}

主库开发已继续向前推进。下列增量已提交到主库，尚未纳入当前公共安装包；
公共版本可用的内容单独列在下一节。

| 方向 | 最新开发内容 | 当前范围 |
| --- | --- | --- |
| 流程网络 | 有限图连接显式进料、分流、混合、换热、分离和多个回路；有限库存与轨迹控制消费者沿用同一世界状态。 | 边界与初始化修复正在核验，完整固定范围资格仍在进行。 |
| 电池观测 | 半电池 DFN 读数支持序列化与恢复，并核对模型和字段。 | 读数仍是派生观测，不是第二份设备状态，也不代表整个半电池任务已完成。 |
| 机理互操作 | 已支持的导入 Cantera 气相网络可保留原物种、反应与单位声明进行导出。 | 要求完整来源声明；不支持或来源缺失的网络明确拒绝。 |
| 物性拟合 | 物理灵敏度诊断要求原模型的有限差分评估实际成功。 | 优化器惩罚值本身不能证明参数可辨识性，失败尝试继续保留。 |

当前开发总表的**56张父任务完成39张**、5张推进中、12张待做；独立 CPU 路线
**31张任务完成4张**。任务完成与软件参考比较不等于所有材料都获验证，
完整科学模型执行仍使用 Python。

## 公共源码中已提供的功能 {#source-synchronization}

公共 Python 运行时仍对应10月25日同步的源码快照
[`823b6b01f`](https://github.com/sunyrain/ChemWorld/commit/823b6b01f)。
从[环境作者指南](environment-authoring.md)选择设备并声明操作、资源边界，
再[接入 Agent，按需定义奖励](environment.md)。三步用户奖励示例已随包提供。

| 方向 | 公共版本可用范围 |
| --- | --- |
| 热力学与界面 | 分子／缔合／多流体模型、多相热量闪蒸、有限过程消费和平面界面计算 |
| 反应与生化系统 | 反应器网络、能量输运、导入机理、SBML／COPASI互操作及有界混合动力学 |
| 水处理与电化学 | 有限膜／处理流程、活性污泥、电池参数与滞后族，以及选定半电池和热工作流 |
| 环境使用 | 用户自定义目标与奖励、持久状态、资源边界、观测和回放 |
| 可选 CPU 开发 | 语义声明、资源／历史基础及 C++20 ABI／绑定骨架；完整数值模型迁移仍在推进 |

安装注册表声明**31个模块、38类部件、52个操作和30类仪器**。这些是软件声明数量，
不代表独立科学领域数，也不代表任意世界都能使用全部组合。官网构建时直接读取
公共注册表计数；能力图谱仍是帮助阅读的内容目录。

通过 Python、CLI 或 Agent 接口使用。旧 Student Lab 命令已退役，
Research Workbench 与 Blender Lab 仍是内部原型。
