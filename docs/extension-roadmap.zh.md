## 当前边界

各模型显式声明来源、单位、相态和有效范围；部分为合成示范，部分含来源化参数。
方程已实现不等于所有材料均获验证。电池与分子热力学主任务仍在推进，独立子模型分别
保留其固定比较结果。

公共包仍提供有界串联与单回路过程消费者。通用有限流程图及其库存／控制集成已在主库推进，
见[最新进展](current-foundation.md#development-progress)。通用自由传播火焰、不受限全局相包络、
完整上游数据库与普适长期老化仍不属于已交付范围。可选 C++ 构建骨架已提供，
科学计算内核及 SIMD 迁移仍在进行。
可用耦合组合见[共享时钟](native_shared_lab.md)。
