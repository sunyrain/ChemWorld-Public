# Interface availability

Current public access uses the [Python environment and CLI](environment.md).
The former Student Lab command has been retired. Research Workbench and Blender
Lab remain development prototypes and are not included in the public package.

Use the [environment authoring guide](environment-authoring.md) to choose apparatus,
set action/resource limits and connect your own agent. The static website's frozen
trace viewer remains available as an illustration, not a live simulator.
