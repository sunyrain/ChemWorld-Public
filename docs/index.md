# Documentation

Install ChemWorld, define an experimental environment and connect your own agent.
These guides describe the interfaces, models and limits of the public implementation.

- [World foundations](world-foundations.md): state, physical models and experimental contracts.
- [Native foundation](native_foundation.md): supported models and their finite scope.
- [API reference](reference.md): interfaces, parameters and executable examples.
- [Current progress](current-foundation.md): what is available in this public snapshot.
