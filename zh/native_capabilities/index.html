    安装原生能力声明¶

    中文预览译文；技术接口与适用范围请同时核对英文原文。

    由 DomainModuleRegistry 生成；不是第二个模块注册。实际的组成、物理规格、设备和任务进一步缩小了操作可用性和数值域。一个模块声明并不能保证任意跨域耦合。

    模块 组成部分 / 策略 范围
    aqueous_mineral 水溶液中的矿物质，有限的碳酸钙-方解石平衡 内容涵盖有限的酸/碱/络合及矿物平衡；包含明确的热力学数据和离子强度范围，但不是地质化学数据库。
    battery_spm 电池容量（mAh），单颗粒电池 合成的 SPM（包含热量/SEI）或明确的等温 SPMe-v1，具有保守的电解质输送；共享的原生循环。明确的等温 DFN 具有耦合的空间反应和通过 24 个平面单元/ 64 个径向单元的固定合成质量。更粗的网格和其他参数需要进行收敛性检查；不涉及实验室验证。没有 PyBaMM 运行时后端。
    continuous_flow 连续流 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    core 材料输入、样品储存、反应 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    crystallization 晶体热力学, 结晶, 有限晶体数量-温度 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    distillation 蒸馏 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    dynamic_distillation 动态蒸馏，有限平衡柱 有限的托盘/接收器库存，以及根据温度和时间进行切割；采用自主设计的动态柱，而非随意的设计。
    electrical_control 瞬态电极，有限时域电极 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    electrochemistry 电化学 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    finite_transport 有限运输，有限泵运输 有限的泵、管道、储罐，以及作者编写的热交换系统；确定的工作点；非任意的多相过程网络模拟。
    lab_schedule 实验室排班表 单过程；具有明确声明的共享时钟策略和原子级有限泵/膜路径的有限独立封闭系统；具有明确定义的 FIFO 的占用状态的有限加热器/分析器身份；不存在相同的容器混合或通用循环。
    liquid_equilibrium 液相平衡, 恒温液相平衡 严格的有限液相平衡，基于已声明的组分性质和支持的组成范围；不进行隐式外推。
    mineral_kinetics 矿物动力学，有限的碳酸钙动力学 有限的碳酸钙溶解/沉淀，伴随着快速的水相平衡；固定为 298.15K，明确的表面几何形状；无矿物核。
    observation 观察 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    phase 阶段 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    programmed_chromatography 程序化色谱法 撰写的峰值/保留率响应，有限的采样，以及持续的迁移；并非一个经过优化的通用色谱分离模型。
    ro_membrane ro膜，有限稀释型 有限理想，稀释NaCl RO在 298.15 度K；合成的沉积污物和有限的冲洗；无反向驱动、膜残留或完全WaterTAP流程图。
    separation 分离 请查阅由作者编写的物理规格和运行合同；不具备普遍有效性声明。
    solid_solution 固溶体, 钙磷相, 二元固相平衡 有限的二进制平衡状态或明确选择的原生 TDB/CEF 阶段；局部组成和热平衡；不进行全局阶段选择。
    sorbent_contact 吸附剂与介质的接触 具有竞争性有限吸附动力学、明确载体和有限清洗；明确的浓缩热量和温度范围。
    stochastic 随机的，吉尔斯皮直接法 整数吉尔斯直接方法；恒定体积/温度下的质量作用；持久性事件和RNG; 不属于空间kMC或自动ODE/SSA切换。
    surface_kinetics 表面反应 拥有有限数量的站点；声明采用单站点/多站点均值场机制和对称相互作用；但不适用于空间kMC或真实的催化剂。
    thermal 热力、加热器连接、自有物料库存温度、静态有限载体库存、历史液体焓 有限功率或显式等温设备；共享能量计算；手动重新连接需要在一个本地时钟模式下禁用一个加热器。
    vacuum_concentration 真空浓度，有限真空浓度焓 有限的成分浓度，使用 VLE/calorics，不支持动力耦合，则被拒绝。
    vapor_liquid_equilibrium 汽液平衡、恒压闪蒸焓 有限的 TP/PH 闭合，包含明确的相/热模型；不存在同时发生的未声明的动力学过程。

    对于已声明的动作单元、参数规则、状态所有权和依赖关系：uv run --no-sync python -m chemworld.examples.native_capabilities --format json
