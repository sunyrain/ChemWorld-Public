    原生扩展与模型范围¶

    公开 Python 后端已包含下列有限模型族。当前基座记录源码与验证状态， API 指南给出可执行输入和输出。

    领域 已实现范围
    共同基座 自有状态、残差/DAE、局部/共享时钟、有限资源、排队测量、精确续算与回放
    热力学 活度/UNIFAC/立方模型、Helmholtz、IF97/冰/湿空气/不可压缩工质、选定分子/缔合/多流体 EOS、局部稳定性与闪蒸
    工程过程 流体关联式、分子热力学串联单元、单回路、有限接收器及有界设计
    反应与输运 气相/表面化学导入、有限图规则生成、能粒、反应器网络、壁面/活塞/热耦合及有限一维输运
    水相与分离 来源化水相/矿物、反应输运、顶空、RO/NF/MD/ED、吸附、树脂/GAC、沉淀、澄清、过滤和洗涤
    固相 选定 CALPHAD/ChemSage 模型、多相 CEF TP/PH、有限二元/三元相图搜索
    电池 SPM/SPMe/DFN、粒径分布、复合/MSMR/半电池等有限模型族、选定控制/热模型、SEI/析锂、阻抗及健康状态
    随机与生化分析 直接法/next-reaction、显式分区混合过程与有限 tau-leap；SBML/SED-ML 子集、稳态/控制、拟合、剖面、通量模式和有限时域增长

    当前边界¶

    各模型显式声明来源、单位、相态和有效范围；部分为合成示范，部分含来源化参数。 方程已实现不等于所有材料均获验证。电池与分子热力学主任务仍在推进，独立子模型分别 保留其固定比较结果。

    任意拓扑流程、通用自由传播火焰、不受限全局相包络、完整上游数据库与普适长期老化 仍不属于本次交付。CPU-01 建立 Python 基线，编译执行和 SIMD 尚待实施。 可用耦合组合见共享时钟。

    参考与复用¶

    生产求解使用原生 Python 后端，可选上游求解器用于独立参考。解析极限、守恒和固定 比较案例检查已实现切片；数值一致不免除来源、数据归属或许可证义务。 用户提供的数据库保留其原许可证。
