    当前基座¶

    本次源码同步¶

    2026 年 10 月 23 日将公开基座从 8a17e23b 同步到已提交源码 963d23f1。 本次原生 Python 后端更新包括：

    • 热力学模型：由活度势导出超额性质与偏摩尔性质、有限参数拟合、六种 UNIFAC 变体、 Twu／PPR78 与 GE 立方混合规则，以及共同均相物性接口。
    • 纯流体 Helmholtz：原生导数、热力学性质、密度求根、饱和、闪蒸与有限热过程消费。 流体系数及来源由调用方显式提供，运行无需上游求解器。
    • 物性方法：温度／参数导数、关联式拟合、科学量转换和显式物性选择策略。 数据身份审查仍在继续，尚不表示所有来源表均已完整覆盖。
    • 工程计算：摩阻与管件、流量计、阀门、泵、填料床／塔、两相流与明渠、粒径分布、 设备／储罐几何及大气／太阳方法。每类关联式保留适用范围，不等同于通用流程求解器。
    • 维护收束：组合与动作解析复用共同实现；回归基线已完成版本归因，历史冻结报告及 原始结果保持原样。

    原生 API 指南提供可运行输入和输出。能力网站新增 Helmholtz、 活度热力学、物性导数和流量计反算示例，继续提供 JSON 与键值表两种结果视图。 CPU 内核重构仍属规划，当前交付使用原生 Python 后端。本次是开发源码同步， 不是新的 PyPI 版本、科学资格验证或性能纪录。

    Windows／Python 3.11 定向集成首轮 769/771 通过。两项失败分别是安装测试 依赖可选参考数据，以及 SciPy 版本导致的 golden 数值差异。拆分可选经验参数检查并 按锁定版本保留原容差后，受影响选择 17 项通过、1 项可选参考检查跳过；该参考 安装检查在具备参考包的 Python 3.12 环境中另行通过。两轮有重叠，不拼接分母。 实际 sdist→wheel 安装、70 个文档示例、3 项公开边界检查、全仓 Ruff、严格双语 构建及 26 项浏览器检查通过。

    全仓类型检查仍未收敛：同环境下 mypy 从前一公开快照的 3,255 项报错变为 3,378 项。 本次不声称整个质量流水线全绿，也未新增跨平台科学资格验证。

    上次公开同步：10 月 22 日¶

    2026 年 10 月 22 日更新将公开基座从 8dc31912 同步到已提交源码 8a17e23b，包含：

    • 外部密度／体积来源（含 CRC 维里数据）及保留来源信息的临界常数输入。

    入口见原生 API和工作流示例。数据来源与应用范围须显式声明；Thevenin 使用经验参数，分别记录电荷与热收支，不推断化学物种。本次公开实现、测试与对照运行器，未重新发布研究原始运行目录，也不构成新的材料准确性验证。

    已同步的能力¶

    能力 当前实现
    材料与容器 创建容器、转移带来源的样品、选择容器，沿声明的组件端口流转物料。
    组件组合 根据依赖、状态归属和资源检查编译兼容的能力网络；报告使用 component-network 及带容器名称的状态归属，替代旧固定模式名称。
    完整结晶流程 采样、过滤、重悬及重复结晶保留相库存、粒群和晶种来源；回收率排除投加晶种，以追踪的起始反应物为分母。
    持续过程控制 设置升温／保持程序、阶段队列和反馈，暂停或继续推进；气压与吹扫具有有限的物料和能量收支。
    连续流股 有限储液、混合槽和收集液之间耦合物料、反应及热过程，并提供有限的电化学通道。
    测量设计 调整NMR、IR、MS的扫描次数、分辨率和稀释倍数；测量消耗样品、时间及成本。兼容的结晶任务还提供粒径测量。
    可控机理 接入酸碱—沉淀耦合网络及水相离子对中间体，以及结晶粒群、杂质夹杂与纯化干预。
    资源与回放 区分请求、提交和拒绝，保留物理消耗，支持当前轨迹的精确回放。
    科学记录 提供通用文档、笔记版本和公开历史组件；论文专用实验执行器不进入公开包。

    操作、组件与仪器由原生模块注册表声明；编译后的世界及任务只开放兼容子集。原生物理通道保留单位，历史 Gym 向量作为兼容投影。原有经典优化和可选强化学习接口继续保留。

    本次在Windows AMD64上完成466项通过、1项跳过（缺少可选外部IDAES参考）的完整检查， Ruff、mypy和中英文文档严格构建通过。Python 3.11.15与3.12.10分别验证了wheel和源码包的 独立安装，覆盖15类任务初始化、打包资源、Student Lab及离线示例的精确回放。 这些是软件集成检查，不构成对历史科学报告的重新资格验证。

    模型范围与旧结果¶

    光谱是合成报告通道，不预测任意真实分子的谱图；未操作的容器不会自行演化； 气体控制尚不包含气体溶解和液相反应；连续流电化学通道也不是完整电池模型。 现有噪声扰动模式可能同时改变物理参数，不应直接作为纯噪声对照。

    原始证据、清单和教程输出保持不变，首页动画同样对应历史轨迹。复现旧版请使用固定版本的 notebook链接，或切换到 db98e800 后运行 scripts/verify_release.py；它核对旧版完整源码，不是当前开发的前置条件。

    当前物理模型与旧版不具有逐数值兼容性。旧的相分配世界中点比较仍可执行并精确回放， 但不再达到旧版差异阈值；当前检查保留这个结果，没有把旧资格报告重新标记为新版通过。
